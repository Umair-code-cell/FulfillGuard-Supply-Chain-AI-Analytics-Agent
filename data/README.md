# Local datasets

This directory contains no database or downloaded CSV files in the public repository.

Run `python -m scripts.make_fixture` to generate a tiny **synthetic** `demo.db` for smoke tests. To use the real historical dataset, obtain the [Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) separately and follow the instructions in the root README to create `olist.db`.

The original repository described the Olist dataset as CC BY-NC-SA 4.0. Verify current terms on the source page before any redistribution or commercial reuse. Neither raw data nor a generated database is bundled here.
